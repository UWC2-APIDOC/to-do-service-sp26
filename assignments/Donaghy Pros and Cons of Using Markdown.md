# Pros and Cons of Using Markdown

We will look at a few pros and cons of using Markdown for documentation.

## Pros of Using Markdown

* Easy to learn and apply in multiple coding tools used for documentation.
* Does **not** require embedded tags.
* Many GitHub tools support Markdown text in the comments.

## Cons of Using Markdown

* Different variations of Markdown are only *slightly* interoperarable.
* You **must** know which version of Markdown you are writing in.
