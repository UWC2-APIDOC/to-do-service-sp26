# Markdown overview

The [Markdown Guide](https://www.markdownguide.org/) describes Markdown as:
>"a lightweight markup language that you can use to add formatting elements to plain text documents."

Keep reading to learn about the benefits and limitations of Markdown.

## Markdown benefits

* Creates styled text _without_ embedding complex formatting tags.
  
* It's easy to learn.

* AI models prefer Markdown.

## Markdown limitations

* Too lightweight to support documentation with complex layouts and global linking.

* Can be intimidating to non-technical reviewers.

* You **must** check which variation of Markdown the documentation publishing tool uses.

## Helpful Markdown tips and resources

* Use a Markdown cheatsheet.

* If you are working in a README.md file in GitHub,  
   don't make changes online as this creates a messy commit log in the repo.
   Instead, make your changes and commits in the clone of your repo on your personal computer.

* If using VS Code on a Mac, press **Cmd-K, V** to preview your file.
